# Aseko Senior Secondary School Website

This project is a static school website for Aseko Senior Secondary School. It provides information for students, parents, and visitors about the school, admissions, academics, staff, achievements, gallery, and contact details.

## Website Overview

The website includes multiple pages such as:

- Home
- About
- Academics
- Admissions
- Gallery
- Achievements
- Staff
- Contact
- Login
- Create Account
- Register

## Features

- Responsive school website layout
- Modern navigation and landing page design
- Academic and admissions information
- Gallery and achievement sections
- Staff and contact pages
- Login and account registration UI

## How to Run

Because this is a static website, you can open the project in any browser.

Option 1:
- Open `index.html` directly in a browser.

Option 2:
- Use a local web server such as VS Code Live Server.
